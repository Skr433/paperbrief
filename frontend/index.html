关于 PaperBrief

PaperBrief 把 PDF 解析成带坐标的文档结构，再基于结构生成汇报材料；材料中的每条结论都带页码锚点，点击即可回到原文核对。它不是"让模型写一段总结"，而是"让每句话都能被你验证"。

技术栈

Python 标准库 HTTP 服务（ThreadingHTTPServer）· PyMuPDF 解析 · BM25 + bge-small 向量重排 · DeepSeek / 本地 Ollama 双后端 · Crossref 引文 · arXiv 推荐 · 单文件前端（无构建）。

已知限制

扫描版 PDF 无 OCR；部分论文参考文献排版特殊时解析条数会偏少（已给出提示）；arXiv 从国内访问偶发超时，已做重试、缓存与友好提示；本地 3B 模型质量弱于云端，定位为离线演示。
