## 四、模块可靠性（30/30 成功）

测试时间 2026-11-08 15:58–16:00（当时线上 v0.14.4），10 个模块 × 3 轮 + 并发 3×3：

| 模块 | 3 轮结果 | 耗时 | 备注 |
| --- | --- | --- | --- |
| 解析 `/api/parse` | 3/3 ✅ | 1.50s（冷）/ 0.05–0.07s（缓存） | 缓存约 29× 提速，stats 稳定 |
| 汇报包 `/api/brief` | 3/3 ✅ | 2.2–2.7s | ai_summary 335–415 字，字段齐全 |
| 问答 `/api/ask` | 3/3 ✅ | 2.2–2.4s | 答案逐字一致，含 8/P100，锚点非空 |
| 译文 `/api/translate` | 3/3 ✅ | 0.04–0.08s | 13 条（含标题），一致 |
| 图谱 `/api/graph` | 3/3 ✅ | 0.03s | 21 节点 / 40 边，一致 |
| 图表 `/api/chart` | 3/3 ✅ | 0.8–1.3s | SVG 2466 字符，图注生成 |
| 引用 `/api/citations` | 3/3 ✅ | 0.02–0.04s | 20 条，含 bbox |
| arXiv `/api/arxiv` | 3/3 ✅ | 7.1–11.1s | 外部依赖最慢；本轮均真实结果（stale=false） |
| 错误路径（key 不存在） | 3/3 ✅ | 0.02–0.04s | 返回 400 `{"error":"请先解析"}`，非 500 |
| 并发问答 ×3 | 3 批 9/9 ✅ | 2.1–2.5s/批 | 无超时、无 5xx |

**发现（非故障，接口契约问题）**：
- `parse` 的 `stats` 嵌在 `doc` 内；`brief` 摘要字段为 `ai_summary`、讲稿为 `script`——调用方按字面字段取值会误判为空，建议补兼容别名并更新接口文档
- 错误路径语义偏粗：不存在 key 返回 400"请先解析"，未区分"不存在"（建议 404）与"未解析"
- LLM 输出非幂等：brief 摘要每轮 335–415 字，措辞有波动（演示截图注意）
- arXiv 失败/离线下的 stale 缓存兜底本轮未触发（没有失败样本），建议做一次断网演练

完整明细见子报告：`模块可靠性_1108.md`
