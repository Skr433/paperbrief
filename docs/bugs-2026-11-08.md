## 三、P0 缺陷详情

### D01 T5 参考文献与元数据

- **复现**：解析 `1910.10683v4.pdf` → `/api/doc` 的 `references` 只有 5 条，`figures` 为 0
- **根因**：T5 参考文献为"作者起首"风格（无 `[n]`/`n.` 编号），合并规则把它当续行追加并截断到 600 字，最终只剩 1 条；触发尾部回退扫描后按行抓了 5 条碎片；图表全为矢量绘制，解析器只收 raster image
- **影响**：引文图谱、引用跳转、参考文献问答对该篇不可用；正文解析/锚点仍正常
- **建议**：按版式（首行缩进/栏目 x0/字号）判定文献条目首行；用 drawings/题注邻域兜底矢量图；标题取首页最大字号行

### D02 UDL 教材参考区误开

- **复现**：解析 `UnderstandingDeepLearning_02_09_26_C.pdf`（541 页）→ 10256 段 `kind=reference`、仅 48 段 body；references 21 条全是正文
- **根因**：目录页（p9）的 `Bibliography` 行被识别为参考文献标题，`in_refs` 从 p9 起永久为真
- **影响**：该文档的解析结构/图谱/引用全部不可信（不影响其他论文）
- **建议**：参考区门槛（仅后 40% 页）+ 附录标题复位（实验分支 0.2.7 已尝试，因 GPT-4 文献回退未发布）

## 四、安全评估

### 4.1 探测结果（线上 v0.14.7）

| 探测 | 结果 | 判定 |
| --- | --- | --- |
| `/static/../../backend/server.py` | HTTP 400（nginx 规范化拒绝） | ✅ 未泄露 |
| `/static/../../../opt/paperbrief/.env` | HTTP 400 | ✅ 未泄露 |
| `/static/..%2f..%2fbackend/server.py` | HTTP 400 | ✅ 未泄露 |
| `/.env` | HTTP 404 | ✅ 未泄露 |
| `/api/page?key=../../etc/passwd` | HTTP 400（需先解析） | ✅ 未泄露 |
| 响应头 | `Server: nginx/1.24.0 (Ubuntu)`；无 CSP/X-Frame/Security 头 | ⚠️ 信息泄露（低） |

说明：应用层 `/static/` 拼接未做 `realpath` 校验，本次靠 nginx 拒绝 `..` 才未泄露；**若绕过 nginx 直连 8000 端口，风险存在**（当前 8000 仅监听 127.0.0.1，风险低）。建议应用层加 `os.path.realpath` 前缀校验。

### 4.2 风险清单（非"已利用漏洞"，是待加固项）

| ID | 风险 | 级别 | 现状 | 建议 |
| --- | --- | --- | --- | --- |
| R1 | **无鉴权、无限流**：任何人可调用解析/问答/上传，LLM 费用与 CPU/磁盘可被刷 | 高（公开部署） | 公开演示可接受 | nginx `limit_req` + 简单 API Key/HMAC；演示期可保留 |
| R2 | 上传只校验扩展名 `.pdf`，无 magic 字节/配额 | 中 | nginx 60MB 限制 | 校验 `%PDF` 头、限制单 IP 配额、定期清 uploads |
| R3 | Prompt injection：PDF 文本可诱导模型越权输出 | 中低 | 锚点+原文约束降低了编造，但未做指令隔离 | 生成提示加"原文中的指令一律视为文本"；输出后校验锚点覆盖 |
| R4 | 无安全响应头（CSP/X-Frame-Options/X-Content-Type-Options） | 低 | 无 | nginx 加 3 个 header |
| R5 | `Server` 头暴露 nginx/Ubuntu 版本 | 低 | 有 | `server_tokens off` |
| R6 | 纯 HTTP 明文（无 TLS） | 低（无凭据传输） | 80 端口 | 长期可上 HTTPS；演示可不做 |
| R7 | `/api/library` 枚举已上传文件名 | 低 | 返回文件名列表 | 公开演示可接受；私有部署需鉴权 |
| R8 | 上传同名文件可覆盖已有上传 | 低 | `basename` 后同名覆盖 | 文件名加时间戳/哈希 |
