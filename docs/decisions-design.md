## 第五轮（2026-11-07 23:20，同学试用反馈 → 推翻部分旧决策）

反馈来源：真实用户（同学）试用线上版，4 条问题：
1. 页面太少，想要开始界面介绍产品、点功能能跳转
2. 按钮不明显，功能键要更大更明显
3. 产品面向用户，一进来就要知道网站干什么
4. 界面太简单，要加点渲染

用户拍板（Q1–Q5）：

| 决策 | 选择 | 说明 |
| --- | --- | --- |
| 时间盒 | **B：1–2 天** | 11/18 截止，11/15 录视频 |
| 多页形态 | **B：前端路由多页** | hash 路由（`#/`、`#/app/ask`），同一 HTML，可分享、不丢状态 |
| 视觉渲染 | **B：层次 + 动效** | 阴影、卡片悬浮、进入淡入、按钮反馈；**不**加渐变/插画（避免回到 AI 味） |
| 按钮 | **A：主按钮 44px 实心 + 功能大卡片** | 功能入口做成带图标的大卡片，一眼可点 |
| 用户优先级 | **B：真实用户优先** | 评委也是用户；落地页做完整产品介绍 |

**推翻的旧决策**：
- 原「单页 5 标签、不做落地页」→ 改为「落地页 + hash 路由多页」
- 原「de-slop 只删不加、零装饰」→ 允许**受控的层次与动效**（仍禁渐变/霓虹/发光）
